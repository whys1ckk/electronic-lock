# Electronic Lock

Embedded-проєкт електронного замка на базі **Arduino Uno (ATmega328P)**.

Проєкт створений для практичного вивчення Embedded Systems та роботи з мікроконтролером на низькому рівні: GPIO, AVR-регістрами, таймерами, PWM, EEPROM та периферійними пристроями.

## Можливості

* введення 4-значного PIN-коду;
* перевірка правильності PIN;
* керування станом замка через State Machine;
* OLED-дисплей для відображення стану;
* керування сервоприводом;
* збереження PIN у EEPROM;
* зміна PIN-коду після перевірки старого PIN;
* debounce кнопок;
* автоматичне повернення замка у заблокований стан;
* керування LED-індикаторами;
* використання `millis()` замість блокуючих `delay()`.

## Hardware

* **Arduino Uno / ATmega328P**
* **SSD1306 OLED 128×64 (I2C)**
* **SG90 Servo**
* 2 кнопки
* 3 LED:

  * Yellow
  * Green
  * Red
* резистори для LED

## Підключення

| Компонент  | Arduino Uno |
| ---------- | ----------- |
| Button 1   | D2          |
| Yellow LED | D3          |
| Red LED    | D4          |
| Green LED  | D5          |
| Button 2   | D6          |
| Servo      | D9          |
| OLED SDA   | A4          |
| OLED SCL   | A5          |
| OLED VCC   | 5V          |
| OLED GND   | GND         |

Кнопки використовують внутрішні `pull-up` резистори, тому натискання визначається як `LOW`.

Проєкт розділений на окремі модулі:


### GPIO

Для роботи з кнопками та LED використовуються AVR-регістри:

* `DDRD` — налаштування напрямку GPIO;
* `PORTD` — керування виходами та `pull-up`;
* `PIND` — читання стану входів.

### State Machine

Замок має чотири основні стани:

```text
LOCKED
GRANTED
DENIED
CHANGE_PIN
```

Стан `GRANTED` використовується після введення правильного PIN, а `DENIED` — після неправильного.

`CHANGE_PIN` використовується для процедури зміни PIN-коду.

### Timer

Для відліку часу використовується `millis()`.

Після правильного або неправильного PIN замок автоматично повертається до `LOCKED` через 2 секунди без використання блокуючого `delay()`.

### Servo

Сервопривід керується за допомогою **Timer1** та апаратного PWM через `OC1A (D9)`.

Для генерації сигналу 50 Hz використовується Fast PWM Mode 14 з `ICR1` як `TOP`.

### EEPROM

PIN-код зберігається у внутрішній EEPROM мікроконтролера.

Для запису використовується `EEPROM.update()`, щоб уникати непотрібного перезапису однакових значень.

## Логіка роботи

### Введення PIN

1. Кнопкою D2 вибирається цифра від `0` до `9`.
2. Кнопкою D6 підтверджується вибрана цифра.
3. Після введення чотирьох цифр PIN перевіряється.
4. Якщо PIN правильний — замок відкривається.
5. Якщо PIN неправильний — відображається `DENIED`.

### Зміна PIN

Для переходу в режим зміни PIN потрібно утримувати кнопку D6 приблизно 2 секунди.

Після цього:

```text
CHANGE_PIN
    ↓
Введення старого PIN
    ↓
Перевірка
    ↓
Введення нового PIN
    ↓
Збереження в EEPROM
    ↓
LOCKED
```

Новий PIN використовується після перезапуску Arduino, оскільки він зберігається в EEPROM.

## Build

Проєкт створений за допомогою **PlatformIO**.

Для компіляції:

```bash
pio run
```

Для завантаження прошивки на Arduino Uno:

```bash
pio run -t upload
```
